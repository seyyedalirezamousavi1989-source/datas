# AURORA QUANT — دیتاست v2 (شواهد استراتژی، استدلال، چندنوبتی، ابزار)

وضعیت: ساخته و ممیزی شد؛ **هیچ مدلی آموزش داده نشده** و کیفیت روی مدل واقعی اندازه‌گیری نشده است.

## ایدهٔ اصلی: انتخاب استراتژی با کد، نه با حدس مدل
مدل ۴B نمی‌تواند از روی متن بفهمد کدام استراتژی روی یک جفت‌ارز جواب می‌دهد. پس `strategy_engine.py` شواهد را محاسبه می‌کند و مدل فقط «کارت‌امتیاز» را می‌خواند:
- ۵ استراتژی قاعده‌محور با پارامتر ثابت و بهینه‌نشده: پولبک EMA، شکست کانال ۲۰ کندلی، بازگشت به میانگین در رنج، برگشت بعد از sweep، شکست فشردگی بولینگر.
- سیگنال روی کندل i، ورود در open کندل i+1، استاپ بر پایهٔ ATR (یا سایهٔ sweep)، حداکثر ۴۸ کندل نگهداری، تساوی استاپ/هدف = استاپ، هزینهٔ اسپرد + اسلیپیج.
- کارت‌امتیاز «تا لحظهٔ t»: فقط معاملاتی که تا t کاملاً بسته شده‌اند، ۲۴ ماه اخیر؛ میانگین R، بازهٔ CI99% بوت‌استرپ، نرخ برد، PF، آمار همین رژیم (ADX) و سیگنال فعال روی آخرین کندل.
- «معنادار» یعنی n ≥ 30 و حد پایین CI99% مثبت؛ هشدار چندآزمونی همیشه چاپ می‌شود.
- تست علیت: کارت‌امتیاز با داده‌ی بریده‌شده در t همان متن را می‌سازد (در ممیزی روی نمونه‌ها هم بررسی می‌شود).

**یافتهٔ صادقانه:** روی کل تاریخچهٔ XAUUSD (نمونهٔ هفتگی ۲۰۲۲–۲۰۲۶) در هیچ لحظه‌ای هیچ استراتژی معنادار نشد (۰ از ۲۴۰). پس بیشتر نمونه‌های واقعی می‌آموزند «شواهد کافی نیست، انتخاب نکن». برای آموزش شاخهٔ «معنادار»، کارت‌امتیاز ساختگی که کاربر در پیام می‌چسباند (`meta.synthetic=true`، ۵۰٪ معنادار) اضافه شده؛ این‌ها نتیجهٔ واقعی هیچ نماد نیستند.

## ممیزی (همه سبز) و ارزیابی
`aurora_forex_v2_audit`: اعداد پاسخ از زمینه/پیام کاربر، نبود look-ahead، تقسیم زمانی با فاصله، سازگاری برچسب «معنادار» با قاعده، درستی خواندن کارت‌امتیاز در هر نمونه، پوشش دو شاخه، نبود ایمیل/رمز/تضمین، هشدار آموزشی، اعتبار tool_callها، تنوع و بازتولید کارت‌امتیاز از تاریخچهٔ بریده‌شده.
`aurora_eval_compact` (harness): اجرا روی خروجی مدل خودت؛ معیارها: عدد ساختگی، هشدار آموزشی، خواندن درست کارت‌امتیاز، مسیریابی ابزار (نام+آرگومان)، نشت ایمیل، ادعای غلط تأیید هویت. پاسخ طلایی ۱۰۰٪ می‌گیرد و تست دارد که خروجی بد را رد کند.
```
python -m local_chat.aurora_eval_compact --rows training_data/aurora_forex_v2/*.jsonl training_data/aurora_self/self_knowledge.jsonl --split test --ollama <مدل>
```

## جفت‌ارزهای دیگر
فقط XAUUSD کندل دارم. `tools/mt5_export_candles.py` را روی ویندوزِ دارای MT5 اجرا کن، بعد:
```
python tools/mt5_export_candles.py --symbols EURUSD,GBPUSD,USDJPY,XAUUSD --out candles
python -m local_chat.aurora_forex_v2 --candles candles --symbols EURUSD,GBPUSD,USDJPY,XAUUSD --out training_data/aurora_forex_v2
python -m local_chat.aurora_forex_v2_audit training_data/aurora_forex_v2 candles
```
مسیر چندنمادی با داده‌ی مقیاس‌شده تست دودی شده (نه با داده‌ی واقعی EURUSD).

## محدودیت‌ها
- هیچ لبهٔ پیش‌بینی ادعا نمی‌شود؛ ۵ استراتژی ساده و ثابت‌اند و هدفشان نشان‌دادن «شواهد» است نه سودآوری.
- برای استفادهٔ زنده، برنامه باید کارت‌امتیاز را روی کندل‌های H1 (چند هزار کندل، نه ۳۰۰) محاسبه و به زمینه اضافه کند؛ این اتصال هنوز در `server.py` انجام نشده (`Engine(df_h1).scorecard(t)` آماده است).
- پاسخ‌ها قالب‌محورند؛ انگلیسی فقط برای انتخاب استراتژی و خودشناسی است. اسکریپت آموزش و قالب tool_calls اجرا نشده‌اند.
